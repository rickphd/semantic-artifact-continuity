Packaging-only follow-up: declare XGBoost in the verification requirements.
The stored-result verifier imports the existing ablation-condition helpers from
a module that imports XGBoost, even though verification does not train models.
The prior local environment already contained it; the minimal CI environment
did not install it. Experimental data, metrics, E1/E2 decisions, original
detectors and figures are unchanged. Use v1.1.1 for the corrected installation
instructions; v1.1.0 remains available as published.

# v1.1.0 - 2026-09-17

This version replaces the active seven-variable experimental package with the
corrected six-variable lineage and adds the controlled-discontinuity and final
human-assessment experiments. The immutable v1.0.0 tag preserves the prior
published state. Scientific results in the two versions must not be mixed.

## Included

- Corrected whole-expression/context-span extraction, train-only lexical
  induction, enriched Gold, six-variable ANOVA interface, RDF/SHACL and traces.
- All 24 main, 126 classical-ablation and 42 CNN1D-ablation runs, with 62,016
  stored predictions and captured semantic-input profiles.
- All 125 lexical settings: full artifacts for 97 admissible settings and
  lexicon/rejection evidence for 28 settings outside the loader contract.
- Eleven independent SHACL cases and 26 continuity cases, preserving original
  versus supplementary detections, mutation definitions, oracles and replay.
- Final human assessment: anonymous A/B decisions, 77 author/AI-assisted
  adjudications, reference, comparisons, agreement statistics and final guide.
- Current figures, editable Figure 4, portable plotting wrapper, source/public
  provenance, dependencies, and verification commands.

## Checks Performed During Packaging

These checks use the public package, not an implicit private working directory:

- Metrics recomputed from all 62,016 predictions; 27 runtime profiles matched.
- Six canonical generation stages completed in a new scratch directory; all
  Gold fields and 59,718 semantic cells matched exactly, RDF was isomorphic,
  and all nine prepared numeric matrices matched exactly.
- Full E1 replay matched 26/26 continuity cases and 11/11 SHACL cases.
- E2 replay matched all 1,200 reference/comparison rows and overall/per-concept
  metrics, including pre-adjudication agreement and kappa.
- Figures 5-11 regenerated byte-identically in the checked environment.

No classifier retraining, new human annotation, exhaustive free-text rationale
audit, or cross-platform reproducibility study was performed for publication.
The original global sentiment annotation protocol remains unverified. E2
assesses concept presence/local polarity, not those global labels.

Private correspondence, identifying annotation metadata, unreviewed annotation
prose, duplicated case packages and trained classifier binaries are excluded.
Historical execution records retain their original hashes and meanings;
separate public hashes identify path-normalized or privacy-projected copies.
Legacy figure specifications and the v1.0.0-specific verifier were removed from
the active tree because they describe superseded results; Git history retains
them. Frozen source whitespace and CSV line endings are preserved for integrity.
